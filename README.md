# SlopBreak

PS4-only single-page jailbreak and payload host.

- Firmware-aware jailbreak flow through 13.52
- Payload Hub with compatibility filters, favorites and recent launches
- PS4 Tools page for system, storage and debug utilities
- Linux loaders and offline cache
- Local GoldHEN PayLoader status
- No PC remote mode or browser file uploader

The host only exposes payloads bundled in the project.
